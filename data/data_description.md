# Dataset Description

File: sales_data.csv (100 rows, 7 columns, from 2024-01-01 to 2024-04-09)

| Column | Meaning |
|---|---|
| Date | Date of the order |
| Product | Product sold (Laptop, Tablet, Phone, Headphones, Monitor) |
| Quantity | Number of units sold |
| Price | Price of one unit (Rs.) |
| Customer_ID | Unique customer code |
| Region | Sales region (North, South, East, West) |
| Total_Sales | Quantity x Price (Rs.) |
